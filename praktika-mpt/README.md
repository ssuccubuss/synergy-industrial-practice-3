# Практика МПТ

Учебное веб-приложение для распределения студентов Московского приборостроительного техникума на производственную практику. Студенты заполняют резюме и выбирают места. Представители организаций оставляют отклики на заявки. Координатор рассчитывает и публикует назначения.

## Запуск на Windows

1. Установите Python 3.10 или новее с [python.org](https://www.python.org/downloads/). При установке отметьте **Add python.exe to PATH**.
2. Распакуйте ZIP. Откройте папку **praktika-mpt**, в которой находятся файлы **README.md** и **server.py**.
3. Щёлкните по адресной строке Проводника, введите **powershell** и нажмите Enter.
4. Запустите сервер.

~~~powershell
py -3 server.py
~~~

Если команда **py** недоступна, попробуйте **python server.py**. На macOS и Linux используйте **python3 server.py**. Устанавливать пакеты через pip не требуется.

5. Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/) в браузере. Оставьте терминал открытым. Чтобы остановить сервер, нажмите **Ctrl+C**.

Если порт 8000 занят, запустите **py -3 server.py --port 8001** и откройте [http://127.0.0.1:8001/](http://127.0.0.1:8001/).

## Демонстрационные учётные записи

Пароль для всех перечисленных записей — **Practice2026!**. Кнопки на экране входа подставляют логин и пароль для трёх основных ролей.

| Логин | Роль | Возможности |
|---|---|---|
| **coordinator** | Координатор | Добавлять студентов, организации и места, менять квоты, рассчитывать и публиковать назначения, выгружать CSV и просматривать журнал |
| **student** | Студент | Редактировать резюме, выбирать до трёх мест по своему направлению, просматривать свои отклики и опубликованное назначение |
| **partner** | Организация | Просматривать заявки на свои места, отмечать заинтересованность, комментировать и просматривать свои опубликованные назначения |

Дополнительные записи для демонстрации — **student2**–**student8**, **partner2** и **partner3**. Карточку добавленной организации координатор использует при создании её мест. Кабинеты представителей заведены для трёх организаций из демонстрационного набора.

## Как показать работу

1. Войдите как **student**. На странице **Моя практика** проверьте резюме Анны Вороновой. Сохраните приоритеты, оставив **Разработку личного кабинета** на первом месте и **Вёрстку и тестирование интерфейсов** на втором.
2. Войдите как **partner**. В разделе **Заявки студентов** раскройте заявку Анны Вороновой, введите комментарий и нажмите **Заинтересованы**.
3. Войдите как **coordinator**. На странице **Распределение** нажмите **Рассчитать**. Исходный набор содержит 8 студентов и 6 мест по квотам. Должно появиться 6 назначений и 2 записи без назначения. Нажмите **Скачать CSV**, чтобы получить ведомость с текущим статусом и приоритетами.
4. Нажмите **Опубликовать**, затем снова войдите как **student**. Анна увидит опубликованное назначение по первому приоритету. При работе в разных профилях браузера достаточно обновить страницу соответствующего кабинета.
5. Координатор может отозвать публикацию. Сохранённые назначения снова станут черновиком. Если изменятся квоты, список студентов, места, отклики или приоритеты, прежний расчёт сбросится. После этого нажмите **Рассчитать** ещё раз.

## Правила расчёта

Модель учитывает только выбранные места, которые соответствуют направлению студента. У каждого студента может быть одно назначение, у места — столько назначений, сколько предусмотрено квотой.

Алгоритм ищет максимальный поток минимальной стоимости. Сначала он назначает как можно больше студентов. Среди решений с одинаковым охватом выбирает вариант с минимальной суммой номеров приоритетов. При равенстве этой суммы предпочтение получают варианты с большим числом положительных откликов организаций. Для одинакового набора данных порядок расчёта воспроизводим.

## Файлы и данные

- **server.py** — локальный сервер, HTTP API, проверка ролей, работа с SQLite и выгрузка.
- **allocation.py** — алгоритм распределения.
- **schema.sql**, **demo.sql** — структура базы и исходные учебные записи.
- **static/** — HTML, CSS и JavaScript для кабинетов.
- **test_allocation.py** — проверки правил распределения.

При первом запуске автоматически создаётся **data/practice.sqlite3**. Данные сохраняются между запусками, сеансы входа действуют до перезапуска сервера или до истечения четырёх часов. Чтобы начать с исходных примеров, остановите сервер и переименуйте папку **data**, например в **data-backup**, затем запустите проект снова.

Учебный сервер работает на локальном адресе. В репозиторий включены исходный код и вымышленные демонстрационные записи. Базу с рабочими данными, отчёт и другие файлы с персональными сведениями в репозиторий не загружайте.
